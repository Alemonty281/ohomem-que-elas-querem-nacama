Desenvolva a página pensando PRIMEIRO em smartphones.

A experiência mobile deve ser a prioridade absoluta.

Desktop será apenas uma adaptação da versão mobile.

No mobile:

Conteúdo centralizado

Largura confortável

Excelente legibilidade

Botões grandes

CTA fácil de tocar

Espaçamento adequado

Nada deve ultrapassar a largura da tela

Nenhum scroll horizontal

VSL perfeitamente adaptado

Imagens responsivas

Tipografia responsiva

Cards adaptáveis

Elementos importantes sempre visíveis sem parecerem apertados

Use uma abordagem mobile-first real, não simplesmente uma versão desktop reduzida.

REGRA IMPORTANTE:

BLACK + BORDÔ + VERMELHO + DOURADO

Fundo principal:

Preto muito profundo

Preto com tons de bordô

Gradientes muito sutis

Cores de destaque:

Vermelho intenso para CTAs

Bordô para blocos e seções

Dourado para detalhes premium

Branco para títulos

Cinza claro para textos secundários

CTA

Oferta

Elementos de urgência

Pequenos destaques

O resultado deve parecer sofisticado, não carnavalesco.
